# Star.web-browser
An elevated web browser designed around simplicity
##Why choose us?
Choose us as it is built on PyQT6 chromium /blink engine and is managed by 1 person, no telemetry will be took, and it is very simple to use.
#Steps to use:
1. Download PyCharm from here: https://www.jetbrains.com/pycharm/
2. Setup Pycharm
3. Paste the code from the file "Star.web source code.py" into Pycharm
4. Press the shortcut Alt+F12 to open Pycharm's terminal
 5. Paste the following command: "pip install PyQt6 PyQt6-Webengine psutil"
 6. Run it
